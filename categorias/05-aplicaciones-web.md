## 🐚 Web shells (referencia)

> Los web shells (C99, b374k, China Chopper, R57, WSO…) son **código malicioso**. Este repositorio **no los enlaza ni distribuye**; se listan solo como referencia de amenaza a **detectar**.

| Concepto | Descripción | Referencia | Precio | Estado |
|----------|-------------|------------| :------: |:------:|
| Web shell (concepto) | Script subido a un servidor web para ejecutar comandos de forma remota. | [MITRE ATT&CK T1505.003](https://attack.mitre.org/techniques/T1505/003/) | — | 📚 |
