# 09 · Active Directory

Catálogo de herramientas para auditar entornos Windows / dominio en laboratorios y proyectos autorizados.

[⬅ Volver al índice](../README.md)

| Herramienta | Descripción | Enlace | Estado |
|-------------|-------------|--------|:------:|
| BloodHound | Mapeo de relaciones y rutas de ataque en AD | [GitHub](https://github.com/SpecterOps/BloodHound) | 📚 |
| SharpHound | Recolector de datos para BloodHound | [BloodHound docs](https://bloodhound.readthedocs.io/) | 📚 |
| Impacket | Colección de scripts Python para protocolos de red Windows | [GitHub](https://github.com/fortra/impacket) | 📚 |
| CrackMapExec / NetExec | Navaja suiza para evaluación de redes AD | [GitHub](https://github.com/Pennyw0rth/NetExec) | 📚 |
| Rubeus | Herramienta de interacción con Kerberos | [GitHub](https://github.com/GhostPack/Rubeus) | 📚 |
| Certipy | Auditoría de AD Certificate Services (ADCS) | [GitHub](https://github.com/ly4k/Certipy) | 🎯 |
| ldapdomaindump | Volcado de información LDAP del dominio | [GitHub](https://github.com/dirkjanm/ldapdomaindump) | 📚 |
| PowerView | Enumeración de AD desde PowerShell | [GitHub](https://github.com/PowerShellMafia/PowerSploit) | 📚 |
| Kerbrute | Enumeración/validación de cuentas Kerberos | [GitHub](https://github.com/ropnop/kerbrute) | 📚 |
