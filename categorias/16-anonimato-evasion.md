# 16 · Anonimato y Evasión

Herramientas para **ocultar el origen** del tráfico, enmascarar la IP y evadir censura o filtrado durante una auditoría autorizada: proxies, VPN y redes de anonimato.

[⬅ Volver al índice](../README.md)

> Leyenda de estado: ✅ utilizada · 📚 conocida · 🎯 por aprender

> 🔒 El anonimato se usa para proteger la operación dentro de un compromiso autorizado, nunca para evadir responsabilidad legal.

---

## 🧅 Redes y sistemas de anonimato

| Herramienta | Para qué sirve | Enlace | Estado |
|-------------|----------------|--------|:------:|
| Tor | Red de enrutamiento cebolla que anonimiza el tráfico a través de múltiples nodos. | [Enlace](https://www.torproject.org) | 📚 |
| Whonix | Sistema operativo que fuerza todo el tráfico a través de Tor para máximo anonimato. | [Enlace](https://www.whonix.org) | 📚 |
| Invisible Internet Project (I2P) | Red anónima superpuesta, orientada a servicios y comunicación interna cifrada. | [Enlace](https://geti2p.net) | 🎯 |
| Psiphon | Herramienta de evasión de censura mediante VPN/proxy. | [Enlace](https://psiphon.ca) | 🎯 |
| JonDo / JonDonym | Red de anonimato tipo *mix* (proyecto descontinuado). | *sin enlace oficial confiable* | 🎯 |
| Alkasir | Herramienta para eludir censura en Internet (proyecto antiguo). | *sin enlace oficial confiable* | 🎯 |

## 🌐 VPN

| Herramienta | Para qué sirve | Enlace | Estado |
|-------------|----------------|--------|:------:|
| CyberGhost VPN | VPN comercial para enmascarar IP y cifrar tráfico (escritorio y móvil). | [Enlace](https://www.cyberghostvpn.com) | 📚 |
| Hotspot Shield | VPN comercial para anonimizar la conexión y evadir filtros. | [Enlace](https://www.hotspotshield.com) | 🎯 |
| TunnelBear | VPN sencilla y multiplataforma. | [Enlace](https://www.tunnelbear.com) | 🎯 |
